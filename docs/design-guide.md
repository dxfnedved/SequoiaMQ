# SequoiaMQ 前端重构设计指南

## 设计风格核心

参考 nodcoding.com 的设计风格，我们将打造一个纯粹、明亮、简洁且现代的用户界面。
### 设计理念

1. **纯粹性**：减少不必要的装饰，专注于功能和内容
2. **明亮单色**：以亮色为主，辅以少量强调色
3. **简洁色块**：使用简单的几何形状和干净的色块划分功能区域
4. **插画与SVG**：运用现代插画和SVG图形增加视觉吸引力，提升用户体验
5. **功能优先**：UI服务于用户操作，确保高效直观的操作体验
