# SequoiaMQ 设计指南

> 此设计指南基于nodcoding.com的现代简约风格，专为SequoiaMQ金融分析平台定制

## 设计原则

### 1. 纯粹明亮
- 使用简洁的单色调配色方案
- 确保足够的留白空间
- 设计元素减少到最小必要程度
- 保持高对比度以确保可读性

### 2. 简洁色块
- 使用明确的色块区分不同功能区域
- 色块应有适当的圆角和微妙的阴影
- 在悬停状态添加微妙的色彩变化
- 使用线性渐变作为装饰元素

### 3. 现代SVG元素
- 优先使用SVG图标和图形
- 添加微妙的装饰元素如点、线和几何形状
- 图形应保持简约风格，不过分复杂
- 使用微动效增强用户体验

## 色彩系统

### 主色调
- 主色 `--primary-color: #6366f1`（靛蓝色）
- 亮色调 `--primary-light: #818cf8`
- 暗色调 `--primary-dark: #4f46e5`

### 功能色
- 成功色 `--success-color: #22c55e`（绿色）
- 警告色 `--warning-color: #f59e0b`（橙色）
- 危险色 `--danger-color: #ef4444`（红色）
- 信息色 `--info-color: #3b82f6`（蓝色）

### 中性色
- 背景色
  - 主背景 `--bg-primary: #ffffff`
  - 次背景 `--bg-secondary: #f9fafb`
  - 第三级背景 `--bg-tertiary: #f3f4f6`
- 文本色
  - 主文本 `--text-primary: #111827`
  - 次文本 `--text-secondary: #4b5563`
  - 第三级文本 `--text-tertiary: #9ca3af`

### 股市特定颜色
- 上涨颜色 `--color-up: #ef4444`（红色）
- 下跌颜色 `--color-down: #22c55e`（绿色）

## 组件指南

### 卡片
- 使用 `.card` 类创建卡片
- 悬停时应该有微妙的提升效果
- 使用装饰元素如顶部彩条或装饰点
- 保持足够的内边距（通常 `1.25rem` 到 `1.5rem`）

### 按钮
- 主要按钮：使用 `.btn-primary` 类，背景为主色
- 轮廓按钮：使用 `.btn-outline` 类，边框为主色
- 按钮应有明确的悬停和激活状态
- 图标按钮使用 SVG 并居中对齐
- 为按钮添加微妙的波纹效果

### 输入框
- 使用 `.input` 类创建输入框
- 聚焦时添加主色边框和微妙的发光效果
- 保持足够的高度（通常 `2.5rem` 到 `3rem`）

### 徽章
- 使用 `.badge` 类创建徽章
- 根据含义使用不同的颜色变体
- 徽章应该小巧并使用完全圆角

## 响应式设计

### 断点
- 手机: < 640px
- 平板: 640px - 768px
- 笔记本: 768px - 1024px
- 桌面: > 1024px

### 布局适应
- 在较小屏幕上减少间距和内边距
- 使用弹性布局和网格布局适应不同屏幕尺寸
- 考虑触摸友好的交互（增大触摸目标）

## 动效指南

### 过渡时间
- 快速过渡: `--transition-fast: 0.15s ease-in-out`
- 常规过渡: `--transition-normal: 0.25s ease-in-out`
- 慢速过渡: `--transition-slow: 0.35s ease-in-out`

### 动效类型
- 对于元素状态变化使用淡入淡出效果
- 对于显示/隐藏内容使用滑入滑出效果
- 对于按钮点击使用波纹效果

## 可访问性

### 对比度
- 文本与背景之间应保持至少 4.5:1 的对比度
- 确保重要信息不仅通过颜色进行传达

### 深色模式
- 使用深色模式时反转颜色
- 减小元素对比度以缓解视觉疲劳
- 文本和功能色需要适当调整以确保可读性

## 插图与装饰

### SVG 图标
- 使用线性简约风格的图标
- 图标线条粗细通常为 1.5-2px
- 图标尺寸通常为 16px-24px

### 装饰元素
- 使用简单的几何图形作为背景装饰
- 装饰元素不应干扰内容可读性
- 装饰元素应当使用低透明度（通常 0.05-0.1）

### 自定义波浪和图形
- 使用 SVG 定义波浪分隔符和自定义图形
- 图形应保持简约并与整体设计风格一致
- 使用主色的变体或低透明度
