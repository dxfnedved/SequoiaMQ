# Title
股票搜索与选择功能优化

# Introduction
改进系统中的股票搜索与选择功能，解决现有的模糊搜索API错误问题，优化用户体验，使股票选择更加直观高效。通过改进搜索的稳定性和响应能力，增强用户操作的流畅度，简化股票添加流程。

## 核心实体
```typescript
// 股票搜索结果项
interface StockSearchItem {
  code: string;       // 股票代码
  name: string;       // 股票名称
  inWatchlist: boolean; // 是否在自选股中
  market: string;     // 市场 (上海/深圳/北京)
}

// 搜索状态
interface SearchState {
  keyword: string;    // 搜索关键词
  results: StockSearchItem[]; // 搜索结果
  loading: boolean;   // 加载状态
  error: string | null; // 错误信息
}
```
