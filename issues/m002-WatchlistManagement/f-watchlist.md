# Title
实现自选股观察列表功能


# Introduction
创建完整的自选股管理功能，让用户可以添加、查看、更新和删除自己关注的股票。该功能包括实时数据刷新、股票详情查看以及批量操作等，为用户提供便捷的股票监控管理体验。

## 核心实体

- WatchlistItem (自选股项目)
  - code: string, 股票代码，主键
  - name: string, 股票名称
  - add_time: datetime, 添加时间
  - notes: string, 用户备注
  - current_price: float, 当前价格 (实时数据)
  - change: float, 涨跌幅 (实时数据)
  - volume: float, 成交量 (实时数据)
  - last_update: datetime, 数据最后更新时间
