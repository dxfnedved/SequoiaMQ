# Title
智能预测功能整合与优化

# Introduction
整合并优化系统的智能预测功能，包括LSTM预测和LLM预测，使其与自选股和策略分析功能紧密结合，提供一致性的用户体验和更高效的预测流程。确保所有预测页面具有响应式设计，能适应不同设备和屏幕尺寸。

## 核心功能
- LSTM和LLM预测页面的功能统一与整合
- 预测结果的可视化展示和比较
- 预测历史记录与追踪
- 预测结果导出和分享
