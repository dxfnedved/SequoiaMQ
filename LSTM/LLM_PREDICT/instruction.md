# 智能股票分析系统使用说明

## 1. 系统概述

智能股票分析系统是一个基于 Python 的命令行工具，集成了多源新闻爬取、技术分析和大模型情感分析等功能。系统使用 DeepSeek 大模型进行新闻情感分析，为用户提供全面的股票分析和预测服务。

## 2. 技术栈

### 2.1 核心依赖

- Python 3.13
- DeepSeek API (大模型服务)
- akshare (股票数据获取)
- pandas (数据处理)
- numpy (数字计算)
- loguru (日志管理)
- python-dotenv (环境变量管理)
- requests (HTTP 请求)
- beautifulsoup4 (网页解析)
- pytest (单元测试)

### 2.2 项目结构

```
├── main.py              # 主程序入口
├── workflow_manager.py  # 工作流管理
├── news_crawler.py      # 新闻爬虫
├── llm_interface.py     # 大模型接口
├── technical_analyzer.py # 技术分析
├── test_technical_analyzer.py # 技术分析测试
├── logger_manager.py    # 日志管理
├── .env                 # 环境变量配置
└── results/            # 分析结果保存目录
```

## 3. 命令行功能

### 3.1 基本命令

```bash
# 分析指定股票（支持股票代码或股票名称）
python main.py analyze -s <股票代码或股票名称>

# 示例：分析平安银行
python main.py analyze -s 平安银行
# 或使用股票代码
python main.py analyze -s sz000001

# 运行单元测试
python -m unittest test_technical_analyzer.py -v
```

在 `.env` 文件中配置以下参数：

```
LLM_API_KEY=your_api_key
LLM_API_ENDPOINT=https://api.deepseek.com/v1
```

## 4. 主要流程

### 4.1 数据获取流程

1. 新闻数据获取

   - 使用 `NewsCrawler` 类获取最近 5 天的相关新闻
   - 支持多个新闻源：
     * 东方财富网（公司新闻）
     * 财联社（电报、深度新闻）
     * 万得（头条新闻、焦点新闻）
   - 对新闻内容进行清洗和格式化
   - 支持 HTML 实体解码和标签清理
   - 智能去重和分类处理
2. 技术指标计算

   - 使用 `TechnicalAnalyzer` 类计算技术指标
   - 支持实时数据更新和历史数据获取
   - 包括 MA(5,10,20)、RSI(14)、MACD 等指标
   - 获取最新的价格和成交量信息
   - 支持多个数据源的自动切换和容错

### 4.2 分析流程

1. 情感分析

   - 使用 DeepSeek 大模型分析新闻情感
   - 评估新闻的传播范围和影响力
   - 识别主要利好和风险因素
   - 分析不同新闻源的情感倾向
   - 支持多维度的市场情绪评估
2. 技术分析

   - 分析价格趋势和成交量变化
   - 评估技术指标的交叉和突破
   - 判断整体技术面走势
   - 支持实时行情数据的动态更新
3. 综合预测

   - 结合情感分析和技术分析结果
   - 生成价格区间预测
   - 提供投资建议
   - 包含详细的分析依据

### 4.3 输出结果

分析结果包含以下内容：

- 股票基本信息
- 新闻统计信息
  - 各新闻源的新闻数量
  - 新闻类型分布
  - 时间分布
  - 新闻影响力评估
- 情感分析结果
  - 情感评分 (-1 到 1)
  - 新闻影响范围 (1 到 5)
  - 市场影响 (利好/利空/中性)
  - 详细的情感因素分析
- 主要利好和风险因素
- 技术指标分析
  - MA均线分析（5日、10日、20日）
  - MACD分析（MACD、Signal、Histogram）
  - RSI分析（14日）
  - 布林带分析（上轨、中轨、下轨）
  - 价格和成交量信息
  - 趋势判断
- 价格预测区间
- 投资建议 (买入/持有/卖出)
- 分析总结

结果会同时显示在控制台并保存到 `results` 目录。

## 6. 注意事项

### 6.1 使用限制

- API 调用频率限制
- 新闻获取数量限制（每个源的限制不同）
- 结果缓存时间限制
- 股票名称查询限制
- 实时数据更新间隔限制

### 6.2 最佳实践

- 合理设置环境变量
- 定期清理结果文件
- 关注 API 额度使用情况
- 优先使用股票代码而不是名称
- 注意新闻源的实时性差异
- 定期运行单元测试确保功能正常

### 6.3 常见问题

1. API 调用失败

   - 检查 API 密钥配置
   - 确认网络连接
   - 查看错误日志
   - 检查 API 额度使用情况
2. 新闻获取失败

   - 检查股票代码/名称是否正确
   - 确认各数据源可用性
   - 尝试调整时间范围
   - 检查新闻源的访问限制
   - 验证网络代理设置
3. 分析结果异常

   - 检查输入数据完整性
   - 查看日志详细信息
   - 确认模型响应格式
   - 验证新闻数据质量
   - 运行单元测试进行验证
4. 技术指标计算问题

   - 确认数据源可用性
   - 检查数据时间范围
   - 验证计算参数设置
   - 查看错误日志详情
